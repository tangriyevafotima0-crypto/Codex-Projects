## 2. Kontrakt Payload Misollari va Salbiy / Chegara (`Negative / Edge-Case`) Ssenariylari Tekshiruvi

### 2.1. Atomik Qisman To‘lov + Majburiy Va’da Sanasi (`POST /api/v1/payments` — `recordPaymentWithRequiredPromise`)
- **To‘g‘ri so‘rov (`201 Created`, `Idempotency-Key: pay-20261112-001`):**
  ```json
  {
    "student_id": "22222222-3333-4444-5555-666666666666",
    "target_invoice_ids": ["77777777-8888-9999-aaaa-bbbbbbbbbbbb"],
    "cash_shift_id": "cccccccc-dddd-eeee-ffff-000000000001",
    "amount_uzs": "300000",
    "currency": "UZS",
    "payment_method": "CASH",
    "promise_date": "2026-11-15"
  }
  ```
- **Salbiy va Poyga (`Negative / Race`) Holatlari:**
  1. **Va’da sanasi berilmagan (`remaining_debt_uzs = "200000" > 0`, `promise_date = null`):** `422 Unprocessable Entity` (`error_code = "PROMISE_DATE_REQUIRED_FOR_PARTIAL_PAYMENT"`), PostgreSQL tranzaksiyasi to‘liq rollback bo‘ladi (`Payment` ham yozilmaydi — `B03`, `T11.03`).
  2. **Bir xil `Idempotency-Key: pay-20261112-001` bilan boshqa summa (`amount_uzs = "400000"`):** `409 Conflict` (`error_code = "IDEMPOTENCY_PAYLOAD_MISMATCH"` — `T10.01`).
  3. **Yopiq smenaga (`CashShift.status == CLOSED`) naqd to‘lov:** `409 Conflict` (`error_code = "SHIFT_CLOSED"` — `T11.01`).
  4. **Teacher JWT tokeni bilan chaqirilsa:** `403 Forbidden` (`error_code = "FORBIDDEN_ROLE"` — `T05.04`).
  5. **Markaz `READ_ONLY` litsenziya rejimida bo‘lsa:** `403 Forbidden` (`error_code = "LICENSE_READ_ONLY_MODE"` — `T19.03`).
